# Ginti

**गिनती — "to count."** A better way to track your money. Simple. Private. Yours.

Ginti is a **local-first, offline** expense tracker built with Expo / React Native. All data
lives in an on-device SQLite database — no accounts, no servers, no analytics.

## Why Ginti

| | |
|---|---|
| 🔒 **100% Private** | Your data never leaves your device. |
| 📶 **Works Offline** | Every feature works with no connection. |
| 👤 **No Account Required** | Open the app and start — no sign-up. |
| ☁️ **No Cloud Storage** | Nothing is uploaded, ever. |
| 📱 **Your Data Stays Yours** | On-device SQLite you fully control. |

## Features

- Track income and expenses with categories
- Spending analytics and breakdowns
- Budgets with alerts
- Recurring subscriptions
- Reminders
- Multi-country / multi-currency onboarding

## Getting started

npm run start
